DAVID SCOTCHFORD WEBSITE - QUICK START GUIDE
================================================================================

PROJECT LOCATION: /home/ubuntu/david-scotchford-website

QUICK COMMANDS:
===============
Development:     pnpm dev              (runs at http://localhost:5173)
Production:      pnpm build            (creates dist/ folder)
Preview:         pnpm preview          (preview production build)
Install:         pnpm install          (install dependencies)

KEY FILES TO EDIT:
==================
Content:         src/pages/*.tsx       (edit page content directly)
Colors:          src/index.css         (CSS variables at top)
Navigation:      src/components/Navigation.tsx
Styles:          src/App.css           (component styles)

PAGES INCLUDED:
===============
✓ Homepage       - Hero section with featured projects
✓ About          - Biography and expertise
✓ Portfolio      - Projects with filtering
✓ Video Gallery  - Choreography reels and performances
✓ Credits        - Professional timeline
✓ Testimonials   - Client quotes
✓ Contact        - Inquiry form and FAQ

DESIGN SPECS:
=============
Colors:          Dark theme with gold accents
Fonts:           Playfair Display (headings), Inter (body)
Responsive:      Mobile, tablet, desktop
Animations:      Smooth transitions and hover effects

DEPLOYMENT:
